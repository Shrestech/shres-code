# Generation model routing pilot v2

This registration amends the [original pilot](generation-model-pilot-2026-09-23.md) before collecting comparative task outcomes. It uses the new identifier `generation-model-pilot-2026-09-23-v2`; the original registration and trial artifacts remain unchanged. The six tasks, three repeats, direct `off` arm, temperature zero, serial execution, task verifiers, main-run 120,000-token cap per spawn, and descriptive-only decision rule remain the same.

ZAI requests `glm-5.3` through [its dedicated tier](../tiers/zai-glm-5.3.patch.yml), matching the backend name reported during the original `glm-5.2` canary. The tier explicitly lists this model because the installed catalog omits it; endpoint and protocol come from the existing ZAI provider, while undeclared capacity and modality use the adapter's deployment defaults. Those defaults are configuration assumptions, not measured model capabilities. Its readiness result requires a matching reported response model. The Ollama service remains `ollama-cloud/deepseek-v4-flash:cloud`; a missing backend identity permits time-bounded configured-service evidence, with no checkpoint claim. Observed identity drift excludes task-quality labels.

Each readiness canary runs the short task once with a 32,000-token cap. Readiness requires matching registered task, model, tier hash, credential variable name, and runner settings; a successful verifier outcome; process exit zero without timeout or budget termination; and a final completed `turn/end`. Missing execution or terminal-event evidence fails readiness even when the verifier passes. The cap counts observed non-cache input plus output and can overshoot between polls; it does not bound billed cost. Main-run execution outcomes remain separate from verifier outcomes.

Run `node bench/routing/model-pilot.mjs plan` to inspect the commands without model calls. `canary --execute` freezes the registration and source snapshot, then collects independent evidence for both services. `launch --execute` requires both canaries to pass and the source and input hashes to remain unchanged. `analyze` reads recorded artifacts. Keep the worktree frozen through execution; source drift after either canary or main model command stops further execution.

The pilot has 36 main trials across both services and cannot demonstrate routing superiority or authorize default JEV replacement. Larger independent task evaluation and routing-specific training remain separate stages in the Shield/Laya plan.
