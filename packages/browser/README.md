# Browser automation

Reference for host-local browser automation packages.

| Package | Responsibility | Context key |
|---|---|---|
| [browserskill](browserskill/README.md) | BrowserSkill runtime provisioning, owned Chrome lifecycle, and conversation-scoped browser tools | `browserSkill` management gateway |

The [BrowserSkill Settings UI](../client/ui-browserskill/README.md) belongs to the client group. Browser state is separate from the user’s everyday Chrome profile.
