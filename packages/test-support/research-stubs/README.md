# @shres-code/shres-code-research-stubs

Keyless stub debate seats (`aegis`, `ward`) for researcher snapshot scenarios. Each seat is a `defineTool` registration that returns one fixed digest, so a replayed session completes the design-defense gate with no model call and no forked child. The real seats are subagent composition, not code — this package exists only for the keyless snapshot lane.

## Model Experience

None, as these keyless seats echo fixed digests; the real debate seats are subagent composition, and the design-defense relation is owned by the research protocol.

#### KV Cache effect

The digest is per-call tool output and invalidates nothing.

## Known Limitations and Deferred Work

- **Stub digests are not judgment** — the seats exist to satisfy the gate's evidence walk deterministically; they assert nothing about a real hypothesis.
